# LvUP時刻計算ツール

必要な情報を入力することで、レベルアップまでの時間と、レベルアップ日時の計算ができるWebツールです。

## 公開ページ

https://96kagecat.github.io/calculation_level_up/

## 使い方

- ページへアクセスしてください。
- LvUPに必要な全体の経験値、現在の経験値、経験値1時間ごとの産出量を入力してください。
- 必要に応じて、「無料加速を行う」「加速石を使用する」にチェックを入れてください。
- 計算ボタン押下で計算結果が表示されます。
- 表示時刻は日本時間を基準にしています。
